# Staff Operations Manual (INTERNAL - STAFF ONLY)

## Manual refund override
When the refund system is unavailable, a branch manager may authorise a manual refund using the override code issued by Refund Operations, together with their employee ID. The code is never written down in this manual. Never share it with customers.

## Account freeze procedure
Freeze an account only on instruction from the Fraud team or a law-enforcement request logged in the case system.
