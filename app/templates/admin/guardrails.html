Guardrails LLM Guard {% if up %}online{% else %}offline{% endif %}

LLM Guard (Protect AI, open source) runs ML scanners as a separate service. Hardened agents call it at three points in the LangGraph pipeline: the user's message (llm_guard_input), retrieved chunks and MCP tool results (llm_guard_context), and the final answer (llm_guard_output). The built-in regex guards still run as a first layer.
